# 班格测试 · SB16 上班牛马人格

一个零依赖的职场趣味人格测试网页。用户完成 12 道工位情景题，得到 16 种上班牛马人格之一，以及班味浓度、精神状态、上班名场面、工位生存建议和可下载的牛马工牌。

## 测试维度

- 开工反应：先动起来 / 先缓一口
- 工作存在感：用交付说话 / 让过程可见
- 受压反应：自己消化 / 当场说清
- 下班边界：到点撤退 / 再撑一下

每 3 道题对应一个维度，不会出现平票。

## 16 种人格

准点战神、职场硬茬、PPT炼丹师、向上管理仙人、工位幽灵、怨气发电机、带薪悟道者、人形已读回执、周报考古学家、会议室盆栽、需求缓冲垫、KPI许愿池、咖啡因赛博格、电子木鱼管理员、薪尽自然凉、班味净化器。

## 使用

直接双击 `index.html` 即可打开，无需安装或构建。

如需通过本地服务器预览：

```bash
ruby -run -e httpd . -p 8080
```

只有在服务器运行期间，`http://localhost:8080` 才能打开；发布到 GitHub Pages 时不需要本地服务器。

## 说明

页面所有答案都在本地浏览器中计算，不上传用户数据。测试结果仅用于互联网语境下的娱乐和自嘲，不是心理诊断、职业测评或离职建议。
